## What's new in v0.2.1

- Meeting Detected popup: the button now reacts to the first click, dismisses instantly, and has a close button (Esc works too).
- Start Meeting now auto-starts recording as soon as the meeting page opens.
- Echo cancellation and noise suppression are now chosen automatically based on headphones vs speakers — the manual toggles are gone.
- New: Diagrams — living architecture diagrams generated from your GitHub repos, with animated data flow, versioning, and old-vs-new compare.
- Update prompts now show what's new (like this one).
- Clearer error messages when transcription can't start.
